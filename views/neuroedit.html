🏗️ System Architecture

01

Next.js Frontend

React-based SPA with image upload, real-time preview, before/after comparison slider, and batch processing queue. Client-side image optimization reduces payload size before API calls.

ReactNext.jsCanvas APIWebSocket
02

FastAPI Gateway

High-performance async Python API that receives images, validates inputs, orchestrates model inference, and streams processed results. Built for horizontal scaling with uvicorn workers.

FastAPIUvicornPydanticasync/await
03

U²-Net Engine

U²-Net (nested U-structure) specifically designed for salient object detection. Generates pixel-level saliency maps that produce rich alpha mattes — capturing hair, fur, and semi-transparent edges that general-purpose segmentation models miss.

PyTorchU²-NetRSU BlocksCUDA
04

Enhancement Pipeline

Post-segmentation processing includes unsharp masking for sharpening, bilateral filtering for noise reduction, and alpha channel composition for transparent background output.

OpenCVNumPyPillowscikit-image

🔬 ML Pipeline Flow

1

Image Ingestion

Upload via Next.js → client-side resize to 1024px max → base64 encode → POST to FastAPI

2

Preprocessing

Decode image → normalize to ImageNet mean/std → resize to model input dimensions → tensor conversion

3

Salient Object Detection

U²-Net forward pass → pixel-level saliency map → threshold to alpha matte with soft edges

4

Mask Refinement

Morphological operations (erode/dilate) → Gaussian blur on edges → alpha matte for smooth transitions

5

Composition & Delivery

Apply mask to original → optional enhancement (sharpen/denoise) → encode PNG with alpha → stream response
