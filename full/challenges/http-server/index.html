Build your own HTTP Server

Learn how HTTP works under the hood by building a fully functional HTTP server from scratch that handles GET requests, serves files, and parses headers.

medium 6 stages ~4h
pythonjavascriptgo
0 / 6 stages completed

Stages

Stage 1

Bind to a port

In this stage, you'll create a TCP server that listens on port 4221.

Your Task

Create a program that starts a TCP server on port 4221. Your server should be able to accept a TCP connection from a client. At this point, it doesn't need to respond — just accept the connection.

How TCP Servers Work

TCP (Transmission Control Protocol) is the backbone of HTTP. Before we can handle HTTP requests, we need to set up a TCP listener. This is the lowest building block of a web server.

Here's what happens when a client connects to your TCP server:

  1. Your server calls bind() to associate a socket with port 4221
  2. Your server calls listen() to start accepting connections
  3. When a client connects, your server calls accept() to accept the connection
server.py 
import socket

def main():
    # Create a TCP socket (AF_INET = IPv4, SOCK_STREAM = TCP)
    server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    
    # Allow port reuse (avoids 'Address already in use' error)
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    
    # Bind to localhost on port 4221
    server_socket.bind(('localhost', 4221))
    
    # Start listening for incoming connections
    server_socket.listen()
    print('Server is listening on port 4221...')
    
    # Accept a connection — this blocks until a client connects
    conn, addr = server_socket.accept()
    print(f'Client connected from {addr}')

if __name__ == '__main__':
    main()
Terminal 
$ python server.py
Server is listening on port 4221...
Client connected from ('127.0.0.1', 52413)

Use the socket module in Python or net module in Node.js to create a TCP server.

Don't forget to set SO_REUSEADDR — this prevents the 'Address already in use' error when you restart your server quickly.

Stage 2

Respond with 200

In this stage, you'll respond to an HTTP request with a 200 OK response.

Your Task

Now that your server accepts TCP connections, make it respond with a valid HTTP response. When any client connects and sends data, respond with:

HTTP/1.1 200 OK\r\n\r\n

Understanding HTTP Responses

An HTTP response consists of three parts:

  1. Status line: HTTP/1.1 200 OK — the protocol version, status code, and reason phrase
  2. Headers: Key-value pairs (we'll add these later)
  3. Body: The actual content (also later)

Each line is terminated by \r\n (CRLF). The headers section ends with an empty line (\r\n\r\n), which separates headers from the body.

💡 Key insight: HTTP is just text sent over TCP. There's nothing magical about it — it's a text protocol with strict formatting rules.
server.py 
import socket

def main():
    server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_socket.bind(('localhost', 4221))
    server_socket.listen()
    print('Server is listening on port 4221...')
    
    while True:
        conn, addr = server_socket.accept()
        print(f'Client connected from {addr}')
        
        # Read the incoming request (we don't need it yet)
        request = conn.recv(1024)
        
        # Send a 200 OK response
        response = 'HTTP/1.1 200 OK\r\n\r\n'
        conn.sendall(response.encode())
        
        conn.close()

if __name__ == '__main__':
    main()

Remember: \r\n is CRLF (Carriage Return + Line Feed). HTTP requires this exact line ending.

The response needs TWO \r\n sequences at the end — one to end the status line, and one empty line to signal the end of headers.

Stage 3

Extract URL paths

In this stage, you'll parse the URL path from the HTTP request and respond differently based on the path.

Your Task

Update your server to:

  • Return 200 OK for the path /
  • Return 404 Not Found for any other path

Parsing the Request Line

The first line of an HTTP request is the request line. It has three parts separated by spaces:

GET /some/path HTTP/1.1
  1. Method: GET, POST, PUT, etc.
  2. Path: The URL path (e.g., /, /about, /users/123)
  3. Version: Usually HTTP/1.1

To extract the path, split the request line by spaces and grab the second element.

server.py 
import socket

def main():
    server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_socket.bind(('localhost', 4221))
    server_socket.listen()
    print('Server is listening on port 4221...')
    
    while True:
        conn, addr = server_socket.accept()
        request = conn.recv(1024).decode()
        
        # Parse the request line
        request_line = request.split('\r\n')[0]
        method, path, version = request_line.split(' ')
        
        # Route based on path
        if path == '/':
            response = 'HTTP/1.1 200 OK\r\n\r\n'
        else:
            response = 'HTTP/1.1 404 Not Found\r\n\r\n'
        
        conn.sendall(response.encode())
        conn.close()

if __name__ == '__main__':
    main()
Terminal 
$ curl -v http://localhost:4221/
< HTTP/1.1 200 OK

$ curl -v http://localhost:4221/nonexistent
< HTTP/1.1 404 Not Found

Split the first line of the request by spaces. The path is the second element (index 1).

Make sure you split the request by \r\n first to get just the request line.

Stage 4

Respond with body

In this stage, you'll send a response body along with the appropriate headers.

Your Task

Implement the /echo/{str} endpoint. It should return the string {str} in the response body. For example, /echo/hello should respond with hello.

Your response must include these headers:

  • Content-Type: text/plain
  • Content-Length: {length of body}

Response Headers

HTTP headers provide metadata about the response. Two critical headers for responses with a body are:

  • Content-Type: Tells the client what format the body is in (e.g., text/plain, text/html, application/json)
  • Content-Length: The exact number of bytes in the response body. This helps the client know when the response is complete.

A full response looks like:

HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\nContent-Length: 5\r\n\r\nhello
server.py 
import socket

def main():
    server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_socket.bind(('localhost', 4221))
    server_socket.listen()
    print('Server is listening on port 4221...')
    
    while True:
        conn, addr = server_socket.accept()
        request = conn.recv(1024).decode()
        request_line = request.split('\r\n')[0]
        method, path, version = request_line.split(' ')
        
        if path == '/':
            response = 'HTTP/1.1 200 OK\r\n\r\n'
        elif path.startswith('/echo/'):
            # Extract the string after /echo/
            body = path[6:]  # everything after '/echo/'
            response = (
                f'HTTP/1.1 200 OK\r\n'
                f'Content-Type: text/plain\r\n'
                f'Content-Length: {len(body)}\r\n'
                f'\r\n'
                f'{body}'
            )
        else:
            response = 'HTTP/1.1 404 Not Found\r\n\r\n'
        
        conn.sendall(response.encode())
        conn.close()

if __name__ == '__main__':
    main()
Terminal

< Content-Type: text/plain
< Content-Length: 11
<

Use string slicing to extract everything after '/echo/' in the path.

Content-Length must be the byte length of the body, not the character length. For ASCII text these are the same, but keep this in mind for Unicode.

Stage 5

Parse headers

In this stage, you'll parse HTTP request headers and use them in your response.

Your Task

Implement the /user-agent endpoint. It should read the User-Agent header from the request and return its value in the response body.

Request Headers

After the request line, HTTP requests contain headers — one per line, formatted as:

Header-Name: header-value

For example, a full request might look like:

GET /user-agent HTTP/1.1\r\nHost: localhost:4221\r\nUser-Agent: curl/7.64.1\r\nAccept: */*\r\n\r\n

To parse headers:

  1. Split the request by \r\n
  2. Skip the first line (that's the request line)
  3. For each subsequent line (until the empty line), split by : to get the header name and value
server.py 
import socket

def parse_headers(request):
    """Parse HTTP headers from a request string into a dict."""
    lines = request.split('\r\n')
    headers = {}
    for line in lines[1:]:  # Skip the request line
        if line == '':
            break  # Empty line = end of headers
        key, value = line.split(': ', 1)
        headers[key.lower()] = value
    return headers

def main():
    server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_socket.bind(('localhost', 4221))
    server_socket.listen()
    print('Server is listening on port 4221...')
    
    while True:
        conn, addr = server_socket.accept()
        request = conn.recv(1024).decode()
        request_line = request.split('\r\n')[0]
        method, path, version = request_line.split(' ')
        headers = parse_headers(request)
        
        if path == '/':
            response = 'HTTP/1.1 200 OK\r\n\r\n'
        elif path.startswith('/echo/'):
            body = path[6:]
            response = (
                f'HTTP/1.1 200 OK\r\n'
                f'Content-Type: text/plain\r\n'
                f'Content-Length: {len(body)}\r\n'
                f'\r\n{body}'
            )
        elif path == '/user-agent':
            body = headers.get('user-agent', '')
            response = (
                f'HTTP/1.1 200 OK\r\n'
                f'Content-Type: text/plain\r\n'
                f'Content-Length: {len(body)}\r\n'
                f'\r\n{body}'
            )
        else:
            response = 'HTTP/1.1 404 Not Found\r\n\r\n'
        
        conn.sendall(response.encode())
        conn.close()

if __name__ == '__main__':
    main()

Remember to normalize header names to lowercase when storing them — HTTP headers are case-insensitive.

Use split(': ', 1) (with maxsplit=1) because header values might contain colons too.

Stage 6

Serve a file

In this final stage, you'll serve files from a directory on disk.

Your Task

Implement the /files/{filename} endpoint. Your server should accept a --directory command-line argument specifying where to look for files.

  • If the file exists, return it with 200 OK and Content-Type: application/octet-stream
  • If the file doesn't exist, return 404 Not Found

Serving Files

Serving static files is a core capability of web servers. The process is:

  1. Extract the filename from the URL path
  2. Construct the full file path by joining the directory with the filename
  3. Check if the file exists
  4. If it does, read its contents and send them with appropriate headers
  5. If not, send a 404 response
🎉 Congratulations! After completing this stage, you'll have built a functional HTTP server that can bind to a port, parse requests, route paths, handle headers, and serve files. These are the same fundamental operations that production web servers like Nginx and Apache perform!
server.py 
import socket
import sys
import os

def parse_headers(request):
    lines = request.split('\r\n')
    headers = {}
    for line in lines[1:]:
        if line == '':
            break
        key, value = line.split(': ', 1)
        headers[key.lower()] = value
    return headers

def main():
    # Parse command-line arguments
    directory = '/tmp'  # default
    if '--directory' in sys.argv:
        idx = sys.argv.index('--directory')
        directory = sys.argv[idx + 1]
    
    server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_socket.bind(('localhost', 4221))
    server_socket.listen()
    print(f'Serving files from {directory} on port 4221...')
    
    while True:
        conn, addr = server_socket.accept()
        request = conn.recv(1024).decode()
        request_line = request.split('\r\n')[0]
        method, path, version = request_line.split(' ')
        headers = parse_headers(request)
        
        if path == '/':
            response = 'HTTP/1.1 200 OK\r\n\r\n'
        elif path.startswith('/echo/'):
            body = path[6:]
            response = (
                f'HTTP/1.1 200 OK\r\n'
                f'Content-Type: text/plain\r\n'
                f'Content-Length: {len(body)}\r\n'
                f'\r\n{body}'
            )
        elif path == '/user-agent':
            body = headers.get('user-agent', '')
            response = (
                f'HTTP/1.1 200 OK\r\n'
                f'Content-Type: text/plain\r\n'
                f'Content-Length: {len(body)}\r\n'
                f'\r\n{body}'
            )
        elif path.startswith('/files/'):
            filename = path[7:]  # strip '/files/'
            filepath = os.path.join(directory, filename)
            if os.path.isfile(filepath):
                with open(filepath, 'rb') as f:
                    body = f.read()
                response = (
                    f'HTTP/1.1 200 OK\r\n'
                    f'Content-Type: application/octet-stream\r\n'
                    f'Content-Length: {len(body)}\r\n'
                    f'\r\n'
                ).encode() + body
                conn.sendall(response)
                conn.close()
                continue
            else:
                response = 'HTTP/1.1 404 Not Found\r\n\r\n'
        else:
            response = 'HTTP/1.1 404 Not Found\r\n\r\n'
        
        conn.sendall(response.encode())
        conn.close()

if __name__ == '__main__':
    main()

Be careful with path traversal attacks. In production, you'd want to verify the resolved path stays within the intended directory.

Use 'rb' mode (read binary) when opening files to handle both text and binary files correctly.
