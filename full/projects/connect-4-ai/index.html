Connect 4 vs AI

Challenge a strong AI powered by minimax with alpha‑beta pruning — it searches millions of positions per move and plays at a very high level.

Tech: JavaScript, Canvas API, Minimax Algorithm, HTML5

Highlights

  • Implemented Minimax with Alpha-Beta pruning to prune the search tree efficiently.
  • Used Zobrist hashing and a transposition table to cache millions of board states.
  • Designed a premium, responsive UI with glassmorphism and glossy HTML5 Canvas rendering.

Impact & Metrics

  • Search depth of 14 moves achieved in real-time on standard client hardware.
  • Transposition table hit rate >60% in mid-game, significantly speeding up calculation.
  • Zero dependencies — built entirely with vanilla JavaScript and CSS.

System Architecture

  • Game loop decoupled from rendering; AI runs in the main thread (optimized) without blocking UI.
  • Bitboard-based move generation allows for O(1) win checking and fast board manipulation.
  • Responsive Canvas renderer handles animations and scaling for all device sizes.

Ownership & Learnings

Solo engineering: implemented the entire game engine, AI strategies, and frontend design.

This Connect 4 implementation isn't just a game; it's a demonstration of classical game AI optimization. I built a Minimax engine that looks 14 moves ahead, using Alpha-Beta pruning to discard irrelevant branches and Zobrist hashing to remember positions it has already seen.

The frontend matches the AI's sophistication with a premium 'Dark Mode' aesthetic. Using the HTML5 Canvas API, I simulated glossy tokens and smooth drop animations. The result is a game that feels native and responsive, running entirely in the browser with no server-side logic required for the gameplay itself.
